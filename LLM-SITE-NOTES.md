# What people say about “LLM websites” — applied here

## Patterns people reject
- Generic AI landing kits (purple gradient heroes, Inter, 3-card grids, “empower your…”)
- Soulless filler copy that could belong to any brand
- Chat widgets whose purpose is unclear (NN/g: users often ignore or distrust site AI chat)
- Overlays and unstable layouts that confuse both humans and agents
- Assumed insider context on the first screen

## Patterns that hold up
- Strong, specific identity (type, colour, voice) that is *not* the training-data average
- Clear “what is this / what do I do” without a sales funnel tone
- Honest unfinished state instead of fake completeness
- Semantic structure and real content over chat-as-default UI
- Agent control (director) as *optional stagecraft*, not the public product

## Changes made from that data
1. Home face: plain orientation (books, language, music) + how to scroll / open More
2. Home detail: “Not a chatbot. Not a product landing page.”
3. Meta description: same clarity for cold search / share traffic
4. Keep unique void + Cormorant + Space Mono (anti-slop)
5. No corner chat widget added
6. Director stays workshop tooling, not the visitor experience
