Director must not be public
--------------------------------
director.html is currently reachable on GitHub Pages (HTTP 200).
.gitignore already lists it, but the file was committed earlier.

From your clone:
  git rm --cached director.html 2>/dev/null || git rm director.html
  # ensure it stays only on your machine
  git commit -m "Remove director.html from public site"
  git push

Also delete it from the repo on GitHub if it remains in history and contained anything sensitive.
