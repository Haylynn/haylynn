# Security

We take the safety of visitors and members seriously.

## Reporting a vulnerability

If you believe you have found a security issue on this website or related services:

1. **Do not** open a public GitHub issue with exploit details.
2. Contact the project maintainer through the private channel listed on the site’s privacy page or official profiles, with a clear description and steps to reproduce where possible.
3. Allow reasonable time for assessment before any public disclosure.

We will acknowledge good-faith reports and work to fix confirmed issues.

## Practices (summary)

- Membership and account data, when enabled, are protected with access controls appropriate to a modern web app.
- Payment processing is handled by established payment providers; card details are not stored on this site’s static files.
- We aim to keep the public site free of private keys and credentials.
- Production deployments should use HTTPS.

## Scope

In scope: the public website and official membership or payment flows tied to it.

Out of scope: third-party sites we link to (music hosts, photography platforms, payment processors, fundraiser hosts), and personal accounts unrelated to this project.

## Thanks

Responsible researchers and users who report issues privately help keep the house safe for everyone.
